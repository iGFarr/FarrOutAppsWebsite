# Farr Out Apps Website

Static website, support center, and privacy policies for Farr Out Apps.

## Local preview

Run any static HTTP server from the repository root, for example:

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deployment

The site deploys to GitHub Pages from `main` using the workflow in
`.github/workflows/pages.yml`.
